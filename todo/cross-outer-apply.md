# CROSS and OUTER APPLY

Support lateral row-source evaluation for the common TVF and correlated
`TOP (1)` patterns generated by applications and ORMs.

## Implementation

- Extend join parsing with `CROSS APPLY` and `OUTER APPLY` nodes that preserve
  left-to-right correlation.
- Flatten safely correlated sources into SQLite-compatible joins or correlated
  subqueries; reject shapes that cannot preserve semantics.
- Preserve `CROSS APPLY` row elimination and `OUTER APPLY` NULL extension.
- Compose APPLY with aliases, predicates, ordering, and nested joins.

## Completion criteria

- Cover APPLY precedence and correlation in parser tests.
- Test TVF and top-one rewrites against real SQLite and SQL Server fixtures.
- Verify NULL-extension and empty-right-side behavior through `tedious`.
- Document unsupported correlation shapes in the relevant agent skills.
